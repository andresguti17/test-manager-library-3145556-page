Manager Library ADSO 3145556 · SDD technical test

A small library, fully managed.

Catalog, members, loans, returns, overdue tracking and most-borrowed reports — one system, two roles.

What it does

Catalog

Books with author, 13-digit ISBN, five fixed categories, copy counts and optional cover. Searchable by title or author.

Members

Borrowers with unique document numbers. No deletions, full history kept.

Loans

One member, 1–3 books, 14-day terms. A member with overdue books or 3 open books cannot borrow more.

Returns & overdue

Line-by-line returns, never counted twice. Overdue list sorted by days late.

Reports

Most-borrowed books per period, grouped by frozen catalog values — renaming a book never rewrites history.

Roles

Admins manage catalog, members and librarians; librarians register loans and returns. Token-based access.

How it is built

API

PHP with Laravel. Hexagonal architecture, single versioned contract under /api/v1.

App

React operations frontend: login, catalog, loans, overdue, reports.

Infra & tool

One-command Docker setup with an empty Postgres engine; demo-data seeder through the API.
